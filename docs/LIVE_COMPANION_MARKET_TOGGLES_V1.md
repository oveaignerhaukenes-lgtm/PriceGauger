# Live Companion market toggles v1

Initial scope is deliberately narrow: Gold and Silver only.

- `Gull` and `Sølv` are independent on/off controls.
- Both default to enabled.
- The current TA Analyst session is spoken only when its market is enabled.
- Other markets are silent until explicitly added to the mapping in a later version.
- This does not yet create independent simultaneous TA Analyst sessions for both markets; it establishes the durable user-facing selection model before the multi-market runtime is added.
