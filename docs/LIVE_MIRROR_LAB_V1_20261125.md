# LIVE Mirror Lab — V3 to V4 research boundary

## Implemented in PR 888
1. **Foundation:** versioned references of all enabled/armed V3 instances. Exact instrument/account/config boundaries, raw filter policies, modifier settings, broker-account observations and BBO availability. No account mutations.
2. **Execution (scenario):** independent persistent sessions, initially MACD+Stoch V2.1 and split R/E V3 long/short, manual control and no unsupported modifiers. Uses the actual pure production strategy functions, canonical close-derived features matching the current LIVE path, separate virtual inventory, existing regime policy, and a quote-driven virtual broker. Actual inventory is used rather than carrying an unfilled desired target. Prior observation uses previous canonical bar; this can diverge from LIVE durable prior memory. Atomic compare-and-swap session update and one settlement per decision. Fresh forward-only flat baseline; no historical paper profits. New config/terms require a new session.
3. **Calibration evidence:** nonblocking bounded LIVE telemetry queue records exact decision keys and actual submission boundary; no broker calls on order path. Existing precheck/cost responses also provide a whitelisted instrument/FX/margin/commission evidence record. Existing exact Saxo FinalFill inspection reads persist verified prices in a separate mirror table. Optional audit loop is disabled by default; with credentials and explicit opt-in it performs at most one exact account audit per 10-minute UTC slot, only on missing recent reconciled fills. Exact joins to decision/submission and already received BBO yield price/latency samples. Reconciliation timestamp is never a fill timestamp.
4. **Validation:** pure frozen chronological calibration and holdout comparisons include unmatched intents, target/inventory/outcome agreement, verified fill coverage, fill price and latency error, and separately verified cash-flow-adjusted P/L windows. Defaults (research criteria, not empirically justified): >=30 calibration fills; >=100 later paired decisions, >=95% coverage, target, inventory and outcome agreement; >=30 verified paired fills with >=95% live-fill coverage, price MAE <=2 points and latency MAE <=2s; >=10 independent account windows with 95th percentile net P/L error <=0.5 percentage points. All thresholds must be frozen before test; insufficient data is not pass.
5. **Evolution prototype:** deterministic mutation of MACD/Stoch weights, entry/exit thresholds, build acceleration and max tranches; bounded to 1000 models per generation and 50 generations. Shares immutable feature frames and the virtual broker. Robust training score penalizes worst chronological fold and drawdown; held-out fold evaluated only after selection. No automatic LIVE promotion. Synthetic scale smoke test is not a production performance benchmark.
6. **UI:** Live-Sim Lab → LIVE Mirror Lab. Displays registered references and scenario session status, plus bounded exact-bar LIVE/SIM diagnostics refreshed every five minutes (unmatched decisions, target/inventory agreement, verified-fill price/latency MAE). Diagnostics are not the frozen holdout acceptance report and cannot unlock evolution. Research only.

## Operation and explicit gates
- Separate LiveSimLab worker starts 2s mirror polling and refreshes reference cohort every 30s. Existing LIVE worker starts bounded telemetry writer. Existing LIVE trading authority and account settings are unchanged.
- Automatic *scenario* enrollment first requires at least 30 exact prior FinalFill/BBO samples per instrument, at least 3 recent account-specific precheck terms covering both sides, explicit NOK conversion/margin and zero-commission illustration; inconsistent/missing terms are rejected. Candidate terms freeze per session. These are estimated broker-model parameters, not proof of execution/P&L parity. Explicit override: configure `PRICEGAUGER_MIRROR_SCENARIO_TERMS` as a JSON object keyed by exact `UIC:AssetType`. Values must supply nok_per_point_per_lot, margin_fraction, fee_nok_per_lot_per_side, latency_seconds, adverse_slippage_points, minimum_lots, optionally max_quote_wait_seconds; capital cap comes from reference policy. These are explicit research terms, not assumed Saxo facts. Do not enable with guessed currency conversion or cost inputs and describe as calibrated.
- Automatic fill audit opt-in: `PRICEGAUGER_MIRROR_AUDIT_ENABLED=1` on research worker only, with existing authorized read-only broker access. Keep disabled until API budget/credentials verified. Existing inspection evidence incurs no additional requests.
- The current reference snapshot reads multiple independent observations; not an atomic Saxo balance/position. Require recent flat inventory heartbeat, no unresolved intent, verified positive NOK account observation and recent BBO. Nonflat, negative, stale, missing or incompatible data are explicit blockers. Do not open/reset a LIVE account to seed a twin.
- `calibration_samples` exposes exact observed samples and missing quotes. `calibrate_fills`, `compare_holdout`, `validate_account_pnl` and `evolve` are research APIs, not a completed automated orchestration of verified datasets. The evolution runner requires an explicit execution + P/L validation report; do not pass synthetic results as empirical proof.
- No 1000-model production run, no verified execution parity, no validated P/L, and no claim of profitability yet.
